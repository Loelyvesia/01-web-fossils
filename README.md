# 网络化石 · Web Fossils

拖动年代时间轴，让整页网页穿越六个视觉时代（CRT / 早期网页 / Y2K / 拟物化 / 扁平化 / 玻璃拟态）。

## 核心互动

年代时间轴 / 展柜点选，整页视觉风格实时切换。

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

构建产物输出到 `dist/`，使用相对路径 `base: './'`，可部署到 GitHub Pages 的任意子路径。

## 技术栈

Vue 3 · TypeScript · Vite · CSS / SVG / Canvas（本作全部视觉为原创代码绘制，无外部图片与付费 API 依赖）。
